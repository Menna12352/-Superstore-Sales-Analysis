# Superstore Sales Analysis

An end-to-end data analysis project focusing on exploring, cleaning, and analyzing the Superstore sales dataset to uncover actionable business insights, trends, and profitability patterns.

## 📊 Project Overview
This project investigates sales performance, customer segments, product categories, and regional profitability using Python and data visualization libraries. The objective is to provide data-driven recommendations to optimize business strategy, reduce shipping durations, and maximize profit margins.

## 🛠️ Key Steps & Features
* Data Preprocessing & Cleaning: Handled missing values (e.g., Postal Code imputation), removed duplicate rows, and prepared clean datasets for modeling.
* Feature Engineering: Created derived features such as Profit Margin and Shipping Duration (calculated from order and ship dates), alongside automated performance categorizations.
* Exploratory Data Analysis (EDA): Utilized Pandas, Matplotlib, and Seaborn to analyze monthly sales trends, regional distribution, and category-wise performance.
* Correlation Analysis: Generated correlation heatmaps to study the interdependencies between sales, discounts, and profits.

## 🧰 Technologies & Libraries Used
* Python (Programming Language)
* Pandas & NumPy (Data Manipulation & Analysis)
* Matplotlib & Seaborn (Data Visualization)
* Jupyter Notebook / VS Code (Development Environment)

## 📈 Key Insights
* Identified top-performing product categories and sub-categories driving the highest revenue.
* Analyzed regional sales distributions to highlight areas requiring better marketing or discounting strategies.
* Examined the impact of discount levels on overall profit margins.
